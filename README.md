# Mythbound

A free-to-play, Link-style hold & spin slot game with a mythic beasts theme. Play money only: nothing can be bought or cashed out.

**Play:** https://watsononlineventures-cell.github.io/Mythbound/

- **iPhone (Safari):** tap **Share**, then **Add to Home Screen**.
- **Android (Chrome):** tap **⋮**, then **Install app**.

After the first launch it plays offline. This branch holds the built game that GitHub Pages serves; the source code is on the `source` branch.
